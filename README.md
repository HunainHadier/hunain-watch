# Hunain Watch

Build a Responsive Vintage Luxury Watch Store Demo Website

Create a modern, premium, fully responsive Vintage Luxury Watch Store demo website using the attached reference image as the primary design inspiration.

Design & Theme

Follow the same vintage luxury aesthetic across every page.

Use dark brown, black, warm beige, and subtle gold colors.

Use elegant typography, premium watch photography, and clean layouts.

Maintain consistent navbar, footer, buttons, spacing, and color palette across all pages.

Avoid unnecessary gradients, bright colors, and clutter.

Required Pages

Home – Hero section, featured watches, new arrivals, and promotional section.

Shop – Product grid with basic category filters.

Product Details – Product image, name, price, description, specifications, and Add to Cart.

Shopping Cart – Selected products, quantity, and total.

Checkout – Demo customer and delivery form.

About Us – Brand story and introduction.

Contact Us – Contact information and contact form.

Login – Email and password form.

Register – Name, email, password, and confirm password.

Functionality

Working navigation between all pages.

Responsive mobile navigation.

Basic frontend cart functionality.

Login and registration UI with basic form validation.

Use sample watch products and realistic placeholder content.

No real payment gateway or backend required. This is only a frontend demo.

Technical Requirements

Use React, TypeScript, and Tailwind CSS.

Use reusable components.

Ensure the website works on mobile, tablet, laptop, and desktop.

Keep the code clean and avoid unnecessary dependencies.

Make all pages visually consistent and functional.

Important: Build all required pages in one implementation. Prioritize the reference image's visual style, responsiveness, and consistent design. Do not add unnecessary features or extra pages.
